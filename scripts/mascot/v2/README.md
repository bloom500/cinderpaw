# Cinderpaw mascot, v2 (alpha)

A 48px pixel creature with 73 animations, four flat colours, drawn as data and
regenerated by script. This is the alpha mascot; a professional redraw is welcome,
and everything here is the brief for it.

- `base-48.png`: the creature at rest. Outline `#000000`, fur `#2c2c2c`, skin `#f1841b`,
  highlight `#ffffff`, transparent background. Traced from a reference render by
  `trace_body.py`, then hand-cleaned in Aseprite (`cinderpaw-v2.base.aseprite`).
- `animations-spec.md`: the 73 states, what triggers each in the app, and the pose.
- `astra/build.blender.py`: the generator. Every state is a list of poses (face,
  squash, head offset, arms as shoulder/elbow/hand, props). Blender is only its Python
  runtime: `blender --background --python astra/build.blender.py -- <state>` writes
  `astra/<state>/NNN.png` (64x64, creature at 8,8) and updates `astra/manifest.json`
  (fps, per-frame durations). `-- source` rebuilds `astra/astra.blend`, one scene per
  state, for review in Blender (Space plays it).
- `check_frames.py astra`: mechanical acceptance (size, exact palette, 2..12 frames,
  horns present). Run after every change.
- `to_frames_ts.py`: packs every frame into `frontend-react/src/components/chat/mascot/sheet.png`
  and writes `frames.ts` (state -> sheet indices, durations as repeated 160 ms ticks).
  The state -> animation mapping lives in this file. Never edit `frames.ts` by hand.

Two rules learned the hard way: a free-standing black stroke vanishes on the dark fur
and on the app surface, so props are orange or white with black only as outline; and
props under ~14px do not read, the budget is 24x24 with 2px strokes.
