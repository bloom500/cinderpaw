Layout notes:
• Sidebar sits inline in a flex row below the topbar — it pushes the canvas right (no overlay)
• border-radius: 0 16px 16px 0 on sidebar right side only (floating pill look)
• Collapse animates sidebar with translateX(-240px) + margin-left: -240px simultaneously — 200ms ease-in-out
• Burger icon (≡) in topbar: visible only when collapsed, hidden when expanded
• State persisted to localStorage
