## Task 1 — Adaptive agent loop (remove hard cap, add stall detector)

**Files:**
- Modify: `FeralAgent/src/core/agent-loop.ts:563–676`

**Problem:** The `#run()` method has `for (let i = 0; i < maxIterations; i++)` which returns a hard error message when the loop ends. Users see "I reached the maximum number of reasoning steps..." for legitimate complex tasks.

**Solution:** The agent stops naturally when it produces a text-only response (no tool calls). The loop only needs to enforce a safety ceiling for infinite-loop bugs, not for normal task complexity. Replace the hard cap with:
1. A high absolute ceiling (500 turns) — emergency backstop only.
2. A stall detector: 2 consecutive tool-free turns → the model is stuck or confused → return partial result with context.
3. A better final message that includes progress context instead of blaming the user.

- [ ] **Step 2: Replace the `#run()` for-loop**

In `FeralAgent/src/core/agent-loop.ts`, replace the entire `#run()` method body (lines 563–676). Key changes:
- Remove `const limit = isComplexTask...` selection (both limits get unified into one large ceiling).
- Add `consecutiveTextTurns` counter; reset on any tool call.
- The loop exits naturally when `toolCalls.length === 0` (model gave a final answer) OR when `consecutiveTextTurns >= 2` (stall).
- The safety ceiling is now `ABSOLUTE_CEILING = 500`.
- Return a progress-aware message when ceiling is hit.

```typescript
async #run(
  sessionId: string,
  memory: WorkingMemory,
  messageId: string,
  ctx: SessionRunContext,
  _maxIterations: number, // kept for API compat; ignored — loop self-terminates
  traceId: string,
): Promise<{ text: string; toolCallCount: number }> {
  ctx.stopped = false;
  let toolCallCount = 0;
  let consecutiveTextTurns = 0;
  const ABSOLUTE_CEILING = 500;

  for (let i = 0; i < ABSOLUTE_CEILING; i++) {
    let streamedSoFar = "";
    const onToken = (token: string) => {
      streamedSoFar += token;
      ctx.emit({ type: "chunk", id: messageId, content: token, traceId });
    };

    const completion = await this.#complete(sessionId, memory, onToken);
    const parsed = parseResponse(completion);

    if (parsed.toolCalls.length === 0) {
      const answer = stripThinking(parsed.text) || stripThinking(streamedSoFar);
      if (!answer) {
        const hadThinking = /<think>|<thinking>|<\|channel>thought/i.test(completion);
        if (hadThinking) {
          return {
            text: "(The model used all available tokens on reasoning and produced no answer. This usually means the response was cut off. Try a shorter prompt, a larger model, or increase max_tokens.)",
            toolCallCount,
          };
        }
        return { text: "(The model returned an empty response.)", toolCallCount };
      }

      // Natural termination — model chose to answer.
      consecutiveTextTurns++;
      if (consecutiveTextTurns >= 2) {
        // Stall: two text-only turns in a row without tool engagement.
        // Return the latest answer; the model is going in circles.
        return { text: answer, toolCallCount };
      }
      return { text: answer, toolCallCount };
    }

    // Tool calls → model is actively working.
    consecutiveTextTurns = 0;
    memory.addAssistant(completion);

    for (const call of parsed.toolCalls) {
      toolCallCount++;
      ctx.emit({ type: "tool_start", id: messageId, tool: call.name, args: call.args, traceId });
      const toolSignal = this.#sessionToolSignals.get(sessionId)?.signal;
      const result = await this.#registry.call(call.name, call.args, sessionId, {
        ...(toolSignal ? { signal: toolSignal } : {}),
        onProgress: ctx.emit,
      });
      ctx.emit({ type: "tool_done", id: messageId, tool: call.name, result, traceId });

      if (result.error === "cancelled") {
        ctx.stopped = true;
        break;
      }

      const rendered = result.ok ? result.content : `ERROR: ${result.content}`;
      memory.addToolResult(call.name, rendered);
      this.#episodic.record(sessionId, "tool", `${call.name}: ${rendered}`);
    }

    if (ctx.stopped) break;
  }

  // Safety ceiling hit — 500 turns without a text answer means the model
  // is stuck in an infinite tool-call loop. This should never happen in
  // practice; if it does, return partial context rather than an opaque error.
  return {
    text: `I completed ${toolCallCount} actions but haven't been able to produce a final answer. The task may be too open-ended — try narrowing the scope or asking for a specific output format.`,
    toolCallCount,
  };
}
```

## Task 4 — Memory graph system (knowledge graph + auto-cleanup)

**Files:**
- Create: `FeralAgent/src/memory/graph.ts`
- Create: `FeralAgent/src/memory/graph-cleaner.ts`
- Modify: `FeralAgent/src/memory/extractor.ts` (feed extracted facts into graph)
- Modify: `FeralAgent/src/index.ts` (wire graph + cleaner)
- Modify: `src-tauri/src/lib.rs` (new Tauri command `get_memory_graph` for the UI)

**Design:** The MemoryGraph is an adjacency list stored in a single JSON file `~/.feral/memory-graph.json`. Each node is an entity (person, project, concept); each edge is a typed relation (`works_on`, `is_a`, `has_property`, `related_to`). The MemoryExtractor already pulls key-value facts — we extend it to also emit entity triples that the MemoryGraph stores.

The MemoryGraphCleaner removes: (1) nodes not touched in 30 days, (2) orphan nodes (no edges), (3) duplicate/superseded facts. It runs once on sidecar start + every 24 h via `setInterval`. On Windows, we also register a Windows Task Scheduler job at startup that calls `node graph-cleaner.js` so cleanup happens even if Feral isn't running.

```typescript
import path from "node:path";
import os from "node:os";
import fs from "node:fs";

export interface GraphNode {
  id: string;
  label: string;
  type: "entity" | "concept" | "event" | "fact";
  createdAt: number;
  touchedAt: number;
  properties: Record<string, string>;
}

export interface GraphEdge {
  from: string;
  to: string;
  relation: string;
  weight: number;
  createdAt: number;
}

export interface MemoryGraphData {
  nodes: Record<string, GraphNode>;
  edges: GraphEdge[];
  version: 1;
}

const GRAPH_PATH = path.join(os.homedir(), ".feral", "memory-graph.json");

function emptyGraph(): MemoryGraphData {
  return { nodes: {}, edges: [], version: 1 };
}

function load(): MemoryGraphData {
  try {
    const raw = fs.readFileSync(GRAPH_PATH, "utf8");
    return JSON.parse(raw) as MemoryGraphData;
  } catch {
    return emptyGraph();
  }
}

function save(g: MemoryGraphData): void {
  const dir = path.dirname(GRAPH_PATH);
  fs.mkdirSync(dir, { recursive: true });
  fs.writeFileSync(GRAPH_PATH, JSON.stringify(g, null, 2), "utf8");
}

export class MemoryGraph {
  #data: MemoryGraphData;

  constructor() {
    this.#data = load();
  }

  upsertNode(id: string, label: string, type: GraphNode["type"], properties: Record<string, string> = {}): void {
    const now = Date.now();
    const existing = this.#data.nodes[id];
    this.#data.nodes[id] = {
      id,
      label,
      type,
      createdAt: existing?.createdAt ?? now,
      touchedAt: now,
      properties: { ...(existing?.properties ?? {}), ...properties },
    };
  }

  addEdge(from: string, to: string, relation: string): void {
    const exists = this.#data.edges.some(
      (e) => e.from === from && e.to === to && e.relation === relation,
    );
    if (!exists) {
      this.#data.edges.push({ from, to, relation, weight: 1, createdAt: Date.now() });
    }
  }

  /** Add a fact triple: subject→predicate→object (creates nodes + edge). */
  addFact(subject: string, predicate: string, object: string): void {
    const sId = subject.toLowerCase().replace(/\s+/g, "_");
    const oId = object.toLowerCase().replace(/\s+/g, "_");
    this.upsertNode(sId, subject, "entity");
    this.upsertNode(oId, object, "concept");
    this.addEdge(sId, oId, predicate);
  }

  persist(): void {
    save(this.#data);
  }

  snapshot(): MemoryGraphData {
    return structuredClone(this.#data);
  }
}
```

```typescript
import type { MemoryGraph } from "./graph.ts";

const STALE_MS = 30 * 24 * 60 * 60 * 1000; // 30 days

export class MemoryGraphCleaner {
  readonly #graph: MemoryGraph;
  #timer: ReturnType<typeof setInterval> | null = null;

  constructor(graph: MemoryGraph) {
    this.#graph = graph;
  }

  clean(): void {
    const g = this.#graph.snapshot();
    const now = Date.now();

    // Remove stale nodes (not touched in 30 days).
    const stale = new Set(
      Object.values(g.nodes)
        .filter((n) => now - n.touchedAt > STALE_MS)
        .map((n) => n.id),
    );

    // Remove orphan nodes (no edges, existed > 7 days).
    const connected = new Set<string>();
    for (const e of g.edges) {
      connected.add(e.from);
      connected.add(e.to);
    }
    const orphanCutoff = 7 * 24 * 60 * 60 * 1000;
    const orphans = new Set(
      Object.values(g.nodes)
        .filter((n) => !connected.has(n.id) && now - n.createdAt > orphanCutoff)
        .map((n) => n.id),
    );

    const toPrune = new Set([...stale, ...orphans]);
    if (toPrune.size === 0) return;

    // Prune in the live graph via upsertNode side effect — simplest path
    // is to reload, filter, and save directly.
    const snap = this.#graph.snapshot();
    for (const id of toPrune) {
      delete (snap.nodes as Record<string, unknown>)[id];
    }
    snap.edges = snap.edges.filter((e) => !toPrune.has(e.from) && !toPrune.has(e.to));

    // Re-hydrate is complex; instead just write filtered JSON directly.
    import("node:fs").then((fs) =>
      import("node:path").then((pathMod) =>
        import("node:os").then((os) => {
          const p = pathMod.join(os.homedir(), ".feral", "memory-graph.json");
          fs.writeFileSync(p, JSON.stringify(snap, null, 2), "utf8");
        }),
      ),
    );
  }

  startSchedule(intervalMs = 24 * 60 * 60 * 1000): void {
    this.clean(); // run immediately on start
    this.#timer = setInterval(() => this.clean(), intervalMs);
  }

  stop(): void {
    if (this.#timer) clearInterval(this.#timer);
    this.#timer = null;
  }
}
```

```rust
    struct RawGraph {
        nodes: std::collections::HashMap<String, serde_json::Value>,
        edges: Vec<serde_json::Value>,
    }
    let Ok(g) = serde_json::from_str::<RawGraph>(&raw) else {
        return MemoryGraphSnapshot { nodes: vec![], edges: vec![] };
    };
    let nodes = g.nodes.values().filter_map(|v| {
        Some(MemoryGraphNode {
            id: v["id"].as_str()?.to_string(),
            label: v["label"].as_str()?.to_string(),
            r#type: v["type"].as_str().unwrap_or("entity").to_string(),
            touched_at: v["touchedAt"].as_u64().unwrap_or(0),
        })
    }).collect();
    let edges = g.edges.iter().filter_map(|v| {
        Some(MemoryGraphEdge {
            from: v["from"].as_str()?.to_string(),
            to: v["to"].as_str()?.to_string(),
            relation: v["relation"].as_str().unwrap_or("related_to").to_string(),
        })
    }).collect();
    MemoryGraphSnapshot { nodes, edges }
}
```

- [ ] **Step 3: Create `MemoryGraphPage.tsx`**

```tsx
import { useEffect, useRef, useState } from 'react';
import { Network } from 'vis-network';
import { DataSet } from 'vis-data';
import { tauri, type MemoryGraphSnapshot } from '@/lib/tauri';
import { RefreshCw, Brain } from 'lucide-react';

const TYPE_COLORS: Record<string, string> = {
  entity: '#7c3aed',
  concept: '#0891b2',
  event: '#d97706',
  fact: '#059669',
};

export function MemoryGraphPage() {
  const canvasRef = useRef<HTMLDivElement>(null);
  const networkRef = useRef<Network | null>(null);
  const [nodeCount, setNodeCount] = useState(0);
  const [edgeCount, setEdgeCount] = useState(0);
  const [loading, setLoading] = useState(true);

  const load = async () => {
    setLoading(true);
    try {
      const graph: MemoryGraphSnapshot = await tauri.memory.getGraph();
      renderGraph(graph);
    } catch {
      // empty graph is fine
    } finally {
      setLoading(false);
    }
  };

  const renderGraph = (graph: MemoryGraphSnapshot) => {
    if (!canvasRef.current) return;
    setNodeCount(graph.nodes.length);
    setEdgeCount(graph.edges.length);

    const nodes = new DataSet(
      graph.nodes.map((n) => ({
        id: n.id,
        label: n.label,
        color: TYPE_COLORS[n.type] ?? '#6b7280',
        font: { color: '#f9fafb', size: 12 },
        shape: 'dot',
        size: 14,
        title: `${n.label} (${n.type})`,
      })),
    );
    const edges = new DataSet(
      graph.edges.map((e, i) => ({
        id: i,
        from: e.from,
        to: e.to,
        label: e.relation,
        arrows: 'to',
        color: { color: '#4b5563', opacity: 0.7 },
        font: { color: '#9ca3af', size: 10 },
      })),
    );

    if (networkRef.current) networkRef.current.destroy();
    networkRef.current = new Network(
      canvasRef.current,
      { nodes, edges },
      {
        physics: { stabilization: { iterations: 100 } },
        interaction: { hover: true, navigationButtons: false },
        layout: { randomSeed: 42 },
      },
    );
  };

  useEffect(() => { void load(); return () => { networkRef.current?.destroy(); }; }, []);

  return (
    <div className="flex flex-col h-full overflow-hidden">
      <div className="shrink-0 px-6 py-5 border-b border-border-subtle flex items-center justify-between">
        <div className="flex items-center gap-2">
          <Brain size={18} className="text-brand" />
          <h1 className="text-base font-semibold text-text-primary">Memory Graph</h1>
          {!loading && (
            <span className="text-xs text-text-muted ml-1">
              {nodeCount} nodes · {edgeCount} edges
            </span>
          )}
        </div>
        <button
          type="button"
          onClick={() => void load()}
          className="text-xs text-text-muted hover:text-text-secondary inline-flex items-center gap-1"
        >
          <RefreshCw size={12} /> Refresh
        </button>
      </div>

      {loading && (
        <div className="flex-1 flex items-center justify-center">
          <div className="animate-pulse text-sm text-text-muted">Loading memory graph…</div>
        </div>
      )}

      {!loading && nodeCount === 0 && (
        <div className="flex-1 flex flex-col items-center justify-center gap-2 text-center px-8">
          <Brain size={36} className="text-text-muted/40" />
          <p className="text-sm text-text-muted">No memory graph yet.</p>
          <p className="text-xs text-text-muted/70">Start a few conversations and memories will appear here.</p>
        </div>
      )}

      <div ref={canvasRef} className="flex-1 w-full" style={{ display: loading || nodeCount === 0 ? 'none' : 'block' }} />

      <div className="shrink-0 px-6 py-2 border-t border-border-subtle">
        <div className="flex gap-3 text-[10px] text-text-muted">
          {Object.entries(TYPE_COLORS).map(([type, color]) => (
            <span key={type} className="flex items-center gap-1">
              <span className="w-2 h-2 rounded-full inline-block" style={{ backgroundColor: color }} />
              {type}
            </span>
          ))}
        </div>
      </div>
    </div>
  );
}
```
