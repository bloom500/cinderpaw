# Feral React Migration — Spec 1: Foundation + Chat Page

**Date:** 2026-05-28
**Status:** Awaiting user review
**Scope:** First of five sub-specs migrating Feral's frontend from Leptos (WASM) to React + TypeScript while leaving the Tauri Rust backend essentially untouched (only specta annotations + Builder pattern added).

This spec covers: Vite/React/TS scaffold, type-safe IPC pipeline, Zustand stores, theming, sidebar shell, and a fully functional Chat page wired to real Tauri commands.

Later specs (out of scope here): Models (spec 2), Agents (spec 3), Settings (spec 4), Cleanup (spec 5).

### 2.2 Formalize inline event payloads

Current state: events emit ad-hoc `serde_json::json!({...})`. To get typed listeners on React, lift each into a struct in a new `src-tauri/src/events.rs`:

```rust
use serde::{Deserialize, Serialize};
use specta::Type;
use tauri_specta::Event;

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct TokenEvent { pub session_id: String, pub text: String }

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct StreamDoneEvent { pub session_id: String }

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct StreamErrorEvent { pub session_id: String, pub error: String }

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct DownloadProgressEvent { pub repo_id: String, pub filename: String, pub progress: f32 }

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct DownloadCompleteEvent { pub repo_id: String, pub filename: String, pub path: String }

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct DownloadErrorEvent { pub repo_id: String, pub filename: String, pub error: String, pub cancelled: bool }

#[derive(Clone, Debug, Serialize, Deserialize, Type, Event)]
#[serde(rename_all = "camelCase")]
pub struct ModelLoadProgressEvent { pub percentage: f64, pub status_text: String }
```

Emit sites change from `app.emit("feral://token", json!({...}))` to `TokenEvent { session_id, text }.emit(&app)`.

**Backward-compat risk (known):** the existing Leptos frontend listens on the literal event names `feral://token`, `feral://stream-done`, etc. tauri-specta's default `Event` derive may use the struct name as the channel name. During implementation, attempt to preserve the literal name via an attribute (`#[tauri_specta::Event(name = "feral://token")]` or equivalent in v2). If that path does not exist:

**Fallback strategy:** keep raw `app.emit("feral://token", payload)` for events (no `Event` derive), but still mark the payload structs with `#[derive(Type)]` so types are exported. On the React side, hand-write typed listeners in `lib/tauri/events.ts` that mirror the generated API surface:

```ts
// Component code MUST NOT change between generated and manual paths.
export const events = {
  tokenEvent: { listen: (cb: (e: { payload: TokenEvent }) => void) => listen<TokenEvent>("feral://token", cb) },
  streamDoneEvent: { listen: (cb) => listen<StreamDoneEvent>("feral://stream-done", cb) },
  // ...
};
```

The component-facing surface stays identical either way.

### 2.3 React-side bindings + façade

**`src/lib/tauri/bindings.ts`** — generated, never edited.

**`src/lib/tauri/index.ts`** — public surface with file-header convention doc:

```ts
/**
 * IPC façade — three usage patterns:
 *
 *   tauri.chat.stream(...)        → throws on error (default; idiomatic for React)
 *   tauri.raw.chatStream(...)     → returns Result<T, string> unchanged
 *
 * Use tauri.raw.* when errors are EXPECTED UX (e.g., model-path validation,
 * "does this file exist" probes). Use the unwrapping API everywhere else.
 *
 * Domain groups (tauri.chat, tauri.conversations, tauri.models, tauri.settings)
 * exist so consumers see ~5 functions per group instead of 29 flat names.
 */
import { commands, type Result } from './bindings';

function unwrap<T>(r: Result<T, string>): T {
  if (r.status === 'error') throw new Error(r.error);
  return r.data;
}

export const tauri = {
  raw: commands,   // escape hatch: raw Result<T, string> wrappers

  chat: {
    stream: async (messages, params, sessionId) =>
      unwrap(await commands.chatStream(messages, params, sessionId)),
    stop:   async () => unwrap(await commands.stopGeneration()),
  },
  conversations: {
    list:   async ()                 => unwrap(await commands.loadConversations()),
    load:   async (id: string)       => unwrap(await commands.loadConversation(id)),
    save:   async (id, title, msgs)  => unwrap(await commands.saveConversation(id, title, msgs)),
    delete: async (id: string)       => unwrap(await commands.deleteConversation(id)),
  },
  models: {
    list:       async () => unwrap(await commands.getModels()),
    loaded:     async () => commands.getLoadedModel(),   // already returns nullable
    load:       async (path) => unwrap(await commands.loadModel(path)),
    startLoad:  async (path) => unwrap(await commands.startModelLoad(path)),
    unload:     async () => commands.unloadModel(),
  },
  settings: {
    get:  async () => commands.getSettings(),
    save: async (s) => unwrap(await commands.saveSettings(s)),
  },
};
export { events } from './bindings';
```

### 2.4 `useChatStream` — race-safe AND unmount-safe

Two disciplines:
1. Listeners registered **before** `chat_stream` is invoked (race-safe; carries forward Leptos comment from `tauri_bridge.rs`).
2. Cleanup runs on unmount even if the user navigates away mid-stream.

```ts
// hooks/useChatStream.ts
type Callbacks = {
  onToken: (text: string) => void;
  onDone:  () => void;
  onError: (err: string) => void;
  onStopped?: () => void;
};

export function useChatStream(externalSessionId?: string) {
  // Internal fallback id so two simultaneous instances can't collide accidentally
  const internalId = useMemo(() => crypto.randomUUID(), []);
  const sessionId = externalSessionId ?? internalId;

  const unlistensRef = useRef<UnlistenFn[]>([]);
  const statusRef = useRef<'idle' | 'streaming' | 'done' | 'error' | 'stopped'>('idle');

  const teardown = useCallback(() => {
    unlistensRef.current.forEach((fn) => fn());
    unlistensRef.current = [];
  }, []);

  const stop = useCallback(async () => {
    if (statusRef.current === 'streaming') {
      statusRef.current = 'stopped';
      await tauri.chat.stop();
    }
  }, []);

  const start = useCallback(async (messages, params, cb: Callbacks) => {
    // Auto-stop a previous stream if caller starts a new one mid-stream
    if (statusRef.current === 'streaming') {
      console.warn('useChatStream: starting new stream while previous still streaming — auto-stopping previous');
      await stop();
      teardown();
    }

    statusRef.current = 'streaming';

    // Register listeners FIRST, await, THEN invoke
    const unlistens = await Promise.all([
      events.tokenEvent.listen((e) => {
        if (e.payload.sessionId !== sessionId) return;
        cb.onToken(e.payload.text);
      }),
      events.streamDoneEvent.listen((e) => {
        if (e.payload.sessionId !== sessionId) return;
        if (statusRef.current === 'stopped') { cb.onStopped?.(); return; }
        statusRef.current = 'done';
        cb.onDone();
      }),
      events.streamErrorEvent.listen((e) => {
        if (e.payload.sessionId !== sessionId) return;
        statusRef.current = 'error';
        cb.onError(e.payload.error);
      }),
    ]);
    unlistensRef.current = unlistens;

    try {
      await tauri.chat.stream(messages, params, sessionId);
    } finally {
      teardown();
    }
  }, [sessionId, stop, teardown]);

  // Unmount safety: stop in-flight stream, drop listeners
  useEffect(() => () => {
    if (statusRef.current === 'streaming') {
      void tauri.chat.stop();
    }
    teardown();
  }, [teardown]);

  return { start, stop, sessionId };
}
```

### 3.1 Store topology — four small stores

| Store | File | Owns | Persistence |
|---|---|---|---|
| `useUI` | `stores/ui.ts` | `sidebarCollapsed`, `theme`, `resolvedTheme` | localStorage via zustand persist |
| `useChat` | `stores/chat.ts` | `sessionId`, `messages`, `streamStatus`, `expandedThinkingIds` | in-memory only |

### 3.2 `useUI` — theming + sidebar

Replaces `next-themes`. ~30 LOC.

```ts
type ThemePref = 'light' | 'dark' | 'system';
type ResolvedTheme = 'light' | 'dark';

const getSystemTheme = (): ResolvedTheme =>
  window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
const resolveTheme = (t: ThemePref): ResolvedTheme =>
  t === 'system' ? getSystemTheme() : t;
const applyTheme = (resolved: ResolvedTheme) =>
  document.documentElement.setAttribute('data-theme', resolved);

export const useUI = create<UIStore>()(persist((set) => ({
  sidebarCollapsed: false,
  theme: 'system',
  resolvedTheme: 'dark',
  toggleSidebar: () => set((s) => ({ sidebarCollapsed: !s.sidebarCollapsed })),
  setTheme: (theme) => {
    const resolved = resolveTheme(theme);
    applyTheme(resolved);
    set({ theme, resolvedTheme: resolved });
  },
}), {
  name: 'feral-ui',
  partialize: (s) => ({ sidebarCollapsed: s.sidebarCollapsed, theme: s.theme }),
  onRehydrateStorage: () => (state) => {
    if (!state) return;
    const resolved = resolveTheme(state.theme);
    applyTheme(resolved);
    state.resolvedTheme = resolved;
  },
}));

export function useSystemThemeSync() {
  const theme = useUI((s) => s.theme);
  useEffect(() => {
    if (theme !== 'system') return;
    const mq = window.matchMedia('(prefers-color-scheme: dark)');
    const handler = () => {
      const resolved = getSystemTheme();
      applyTheme(resolved);
      useUI.setState({ resolvedTheme: resolved });
    };
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, [theme]);
}
```

**Pre-paint theme write in `main.tsx`** — avoids light-then-dark flash on cold start:
```tsx
const stored = JSON.parse(localStorage.getItem('feral-ui') || '{}');
const pref = stored?.state?.theme ?? 'system';
const resolved = pref === 'system'
  ? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')
  : pref;
document.documentElement.setAttribute('data-theme', resolved);
```

### 3.4 Tailwind + shadcn — wiring the palette

**Conflict:** shadcn expects `--primary`, `--accent`, `--muted`, `--background`, etc. Your palette uses semantic names. shadcn's `--accent` (hover bg semantic) clashes with your `--accent` (brand orange).

**Resolution:** dual-layer CSS variables. Your semantic names are source of truth. shadcn names alias to them, with the mapping chosen so shadcn primitives respect your "accent sparingly" rule.

```css
/* src/styles/globals.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

/*
 * ───────────────────────────────────────────────────────────────────────
 * CRITICAL NAMING CONVENTION — read before editing this file
 *
 * 1. Our BRAND color (warm orange) is exposed as --brand / --brand-hover /
 *    --brand-muted. The user-facing palette in spec docs may call this
 *    "accent" — the variable name is intentionally different here to avoid
 *    a fatal collision with shadcn's --accent (which we hijack below).
 *
 * 2. shadcn's --accent below is intentionally bound to --bg-hover (NOT to
 *    our brand). This prevents every shadcn primitive (DropdownMenuItem,
 *    Select, etc.) from painting brand orange on hover, which would violate
 *    the "accent used sparingly" design rule.
 *
 * 3. shadcn's --primary and --ring are bound to var(--brand) so buttons and
 *    focus rings DO use the brand orange.
 *
 * DO NOT rename --brand back to --accent, and DO NOT remove the --accent →
 * --bg-hover mapping. The two would collide (CSS uses last declaration)
 * and the brand color would silently disappear. See spec 1 §3.4.
 * ───────────────────────────────────────────────────────────────────────
```

```tsx
export function MessageList() {
  const messages = useChat((s) => s.messages);
  const status = useChat((s) => s.streamStatus);
  const containerRef = useRef<HTMLDivElement>(null);
  const isAtBottomRef = useRef(true);

  useEffect(() => {
    const el = containerRef.current;
    if (!el) return;
    const onScroll = () => {
      const threshold = 40;
      isAtBottomRef.current = el.scrollHeight - el.scrollTop - el.clientHeight < threshold;
    };
    el.addEventListener('scroll', onScroll, { passive: true });
    return () => el.removeEventListener('scroll', onScroll);
  }, []);

  useEffect(() => {
    const el = containerRef.current;
    if (el && isAtBottomRef.current) el.scrollTop = el.scrollHeight;
  }, [messages, status]);

  // Virtualization deferred. Add react-virtuoso if profiling shows scroll
  // jank or messages.length > 500 routinely. See spec 1 §4.5.
  return (
    <div ref={containerRef} className="flex-1 overflow-y-auto px-4 py-6 space-y-6">
      {messages.map((m) => <MessageItem key={m.id} message={m} />)}
      {status === 'streaming' && <StreamingIndicator />}

  );
}
```

```ts
export function splitThinking(raw: string): { thinking: string | null; answer: string; thinkingComplete: boolean } {
  const openIdx = raw.indexOf('<think>');
  if (openIdx === -1) return { thinking: null, answer: raw, thinkingComplete: true };
  const closeIdx = raw.indexOf('</think>', openIdx);
  if (closeIdx === -1) return { thinking: raw.slice(openIdx + 7), answer: '', thinkingComplete: false };
  return { thinking: raw.slice(openIdx + 7, closeIdx), answer: raw.slice(closeIdx + 8).trimStart(), thinkingComplete: true };
}
```

### 4.12 Sending — orchestration

```ts
// hooks/useSendMessage.ts
export function useSendMessage() {
  const stream = useChatStream(useChat.getState().sessionId);

  return useCallback(async (text: string) => {
    const chat = useChat.getState();
    const userMsg: ChatMessage = { id: uuid(), role: 'user', content: text, createdAt: Date.now() };
    const asstMsg: ChatMessage = { id: uuid(), role: 'assistant', content: '', createdAt: Date.now() };
    chat.addMessage(userMsg);
    chat.addMessage(asstMsg);
    chat.setStreamStatus('streaming');

    const messages = [...chat.messages, userMsg].map(toIpcMessage);
    const params = currentInferParams();

    await stream.start(messages, params, {
      onToken:   (text) => useChat.getState().appendToStreamingAssistant(text),
      onDone:    () => {
        useChat.getState().setStreamStatus('done');
        autoSaveIfEligible();
      },
      onError:   (err) => useChat.getState().setStreamStatus('error', err),
      onStopped: () => useChat.getState().setStreamStatus('stopped'),
    });
  }, [stream]);
}

// Auto-save guard rails
function autoSaveIfEligible() {
  const chat = useChat.getState();
  const hasUser = chat.messages.some((m) => m.role === 'user');
  const hasCompleteAssistant = chat.messages.some(
    (m) => m.role === 'assistant' && m.content.trim().length > 0,
  );
  if (chat.streamStatus !== 'done' || !hasUser || !hasCompleteAssistant) return;
  void useConversations.getState().saveCurrent(autoTitle(chat.messages));
}
```

**Auto-save rules:**
- Save when: `streamStatus === 'done'` AND ≥1 user msg AND ≥1 non-empty assistant msg
- NEVER save on: `streamStatus === 'error'` OR `streamStatus === 'stopped'`
- "Save anyway" button shown in message-area footer when status is `error` or `stopped` → manual save bypassing the guard

### 4.13 Supporting helpers (referenced above)

Small utilities that appear in earlier snippets without their own subsection:

- **`currentInferParams()`** — reads from `useSettings()` (loaded on app boot via `tauri.settings.get()`) and the reasoning-toggle state in `useChat`. Returns an `InferParams` object matching the Rust struct: temperature, top_p, max_tokens, etc. Lives in `lib/inferParams.ts`. Spec 1 just passes the saved defaults; per-message overrides land in spec 4.
- **`toIpcMessage(m: ChatMessage): Message`** — maps the React-side `ChatMessage` (which carries `thinking`, `thinkingDurationMs`, UI metadata) to the backend `Message` shape (only `role` + `content`). When sending to `chat_stream`, we send the assistant's *answer* portion only — the thinking content is not part of the conversation history sent to the model. Lives in `lib/messageMapping.ts`.
- **`CodeBlock`** — custom `<pre>` wrapper used in `Markdown`. Adds a copy-to-clipboard button in the top-right corner of each code block via `@tauri-apps/api/clipboard`. Lives in `components/chat/CodeBlock.tsx`.

- **`autoTitle(messages: ChatMessage[]): string`** — returns the first 40 chars of the first user message, trimmed, with ellipsis if truncated. Falls back to `"New chat"` if no user message exists. Lives in `lib/autoTitle.ts`.

1. **Event-name backward-compat (§2.2).** Validate `#[tauri_specta::Event(name = "feral://token")]` exists in v2. If not, fall back to manual typed wrappers in `lib/tauri/events.ts` mirroring the generated surface.

3. **specta v2 + Tauri 2.11.2 compatibility.** Verify `specta-typescript` version matches `tauri-specta` peer dep at install time.
4. **highlight.js theme conflict.** Both themes imported globally may double-paint via CSS specificity. The `:where()` scoping in §3.4 should win; if it doesn't, switch to dynamic CSS link swap on `setTheme`.
5. **Capability scope (§5.6).** `src-tauri/capabilities/*.json` likely needs updates for the new event channels and any new permissions exposed by tauri-specta's Builder integration. Verified in DoD checklist.
