## Tone guide

- Direct, not defensive
- Named opponents (frontier AI companies) when relevant, not vague generalities
- Concrete examples over abstract principles
- Source everything (papers, blog posts, video links)
- End with clear CTA — never "hope you enjoyed", always "do X"
